二、8 项功能具体分工
功能模块 开发 → 提测 UI / App 要做什么 后端 & 设备端配合
1. UI 视觉规范 第 1 周
第 2 周提测
 按 1.4 规范统一换掉全 App 的颜色、圆角、按钮、输入框和弹窗基础组件。 无需接口改动；测试按规范截图逐项核对样式。
2. 配网流程改版 第 1 周
第 2 周提测
 X5 扫码、S3 网关、LoRa 配对流程换新界面和进度圆环，逻辑沿用现有代码。 沿用现有配网接口和固件协议，仅测试回归三路配网真机。
3. 预约功能 第 1 周
第 2 周提测
 新建定时列表、单次/循环编辑、地图区域选择和时间冲突提示（第1周先用假数据，11.30 接真接口）。 后端：11.27 前完成定时增删改查、判重、云端触发。
设备：11.30 前出能执行定时的固件并上报遥控器接管状态。
4. 割草记录查询 第 1 周
第 2 周提测
 替换掉现有占位页，做出按月筛选列表（含待开始等 5 态）、记录详情（有/无底图展示）和删除。 后端：11.27 前完成统计与查询接口（按月筛选、合并手动/定时列表、删除和待开始状态）。
设备：按现有协议正常上报任务状态即可，不用单独上传记录文件。
5. 控制面板改版 第 2 周
第 3 周提测
 首页改用组合 B 布局：新顶栏、地图铺底、悬浮按钮、底部控台卡、阻挡/回桩/关机弹窗、双模式遥控画面。 后端：配合首页「下次割草」预览字段。
设备：沿用现有 103/107/108/117/bit7 指令与状态上报。
6. 消息中心 第 2 周
第 3 周提测
 新建消息页面：首页右上角图标与红点角标、分类列表、全部已读、点击跳故障/记录/OTA 页。 后端：12.02 前完成消息列表、未读数、已读和 MQTT 推送。
设备：12.02 前配合故障/完成/回桩失败等事件上报。
7. 个人中心 第 2 周
第 3 周提测
 我的页面和帮助/隐私/权限/关于等换新样式；补做个人设置、时区、公英制单位、国家地址和注销设备检查。 后端：12.02 前完成个人资料、偏好（时区/单位/地址）和注销前设备校验接口。
设备：无需配合。
8. Alpha 建图流程 第 3 周
12.14–15 提测
 在现有建图代码上按 1.4 改版并补齐：建图前检查弹窗、开到起点、横屏沿边（回退/擦除/接管）、覆盖、通道和保存。 后端：配合建图地图上传和状态查询。
设备：12.04 先出联调固件，12.10–11 和 App 拿真机走通主流程。

两个卡住节奏的关键点

  • 12.14–15 只有两天测建图：设备端务必在 12.04 给出建图固件，App 第 3 周四（12.10）就和设备、测试先拿真机跑通，别全留到 12.14 再测。
  • 后端和设备端提前一周动：预约/记录第 2 周就提测，消息/个人中心第 3 周就提测，接口和固件如果等 App 写完才开始，提测时只能测假数据。
